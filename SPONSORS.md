# Support LitheView

Financial sponsorship helps fund public examples, documentation, compatibility
testing, and community support. A public sponsorship provider has not yet been
configured. Organizations interested in sponsoring this work can contact
`1061517027@qq.com` with the subject `LitheView sponsorship`.

Sponsorship is voluntary and does not provide a commercial Runtime license,
private source access, product endorsement, priority support, or influence over
security decisions unless a separate written agreement explicitly provides
those benefits.

When a GitHub Sponsors or other public funding account is available, its
verified URL will be added to `.github/FUNDING.yml`. Do not send funds to links
posted in issues or comments.
