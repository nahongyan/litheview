# Support

## Community support

Use GitHub Issues for reproducible SDK integration bugs and documentation
problems. Include the LitheView version, Windows version, compiler and CMake
versions, relevant logs, and a minimal reproduction. Remove credentials,
tokens, personal data, and proprietary application code before posting.

Use GitHub Discussions for usage questions and integration patterns when that
feature is enabled. Community responses and response times are not guaranteed.

## Commercial support
